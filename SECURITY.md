# Segurança

Não incluir segredos, dados reais de viajantes, tokens ou ficheiros `.env` no
repositório. Para comunicar uma vulnerabilidade, contactar o responsável do projeto de
forma privada e incluir passos de reprodução, impacto e evidência mínima necessária.

O projeto exige isolamento por tenant, RLS e validação de entradas. Não abrir issue
pública para vulnerabilidades de segurança antes de uma correção estar disponível.
